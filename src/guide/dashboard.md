# Dashboard

Le dashboard est la page d'accueil de Puna après connexion. Il offre une vue d'ensemble de votre activité avec des **statistiques** et des **graphiques interactifs**.

## Compteurs globaux

En haut du dashboard, trois compteurs affichent :

- **Sites** — Nombre total de sites créés
- **Formulaires** — Nombre total de formulaires
- **Soumissions** — Nombre total de soumissions reçues

## Widgets graphiques

Le dashboard utilise **ApexCharts** pour afficher des visualisations interactives.

### Inbox Counts

Graphique en lignes/barres affichant le **nombre de soumissions par jour**.

- Périodes disponibles : **7 jours** ou **30 jours**
- Permet de visualiser les tendances de réception

### Inbox Percentages

Affiche les **variations en pourcentage** de vos soumissions :

- Aujourd'hui vs hier
- Cette semaine vs semaine précédente (7j)
- Ce mois vs mois précédent (30j)

### Top Forms

**Top 5 des formulaires** classés par nombre de soumissions. Permet d'identifier rapidement vos formulaires les plus actifs.

### Top Site Radial

Affiche votre **site principal** avec une répartition par formulaire sous forme de graphique donut.

### Site Distribution

Graphique de **répartition des soumissions par site**. Utile pour voir quel site génère le plus de feedbacks.

### Inbox Heatmap

**Heatmap jour × heure** montrant la répartition temporelle de vos soumissions.

- Périodes disponibles : **7j**, **30j**, **90j**, **180j**
- Permet d'identifier les heures et jours de pic d'activité

## Navigation

Le menu latéral vous donne accès à :

| Élément       | Description                           |
| ------------- | ------------------------------------- |
| **Dashboard** | Statistiques globales (page actuelle) |
| **Sites**     | Gestion de vos sites et formulaires   |
